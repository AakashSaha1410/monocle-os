# Client inputs

The client's own written material about their process, verbatim. These are the
primary sources everything else in this folder is derived from.

| File | What it is |
|---|---|
| [`dan-process-document.md`](dan-process-document.md) | The process in the client's own numbering, provided 31 July 2026 and walked through line by line over 135 minutes. This is the spine of the whole build |
| [`dan-permutations-needs-list-communications.md`](dan-permutations-needs-list-communications.md) | The permutations and what each one adds, the standard needs list, every communication with its sender and recipient, and the nineteen states that require an attorney. Filed 15 September 2026 — **the newest source, and it wins wherever it differs from anything earlier** |

Each file opens with a short note on what it governs and what it changed, then the
original text.

**One alteration, marked.** A private individual's surname is removed from the
15 September note and shown as `[surname removed]`. The first name is kept so the
sentence still reads. Nothing else in these two files has been changed — no
tidying, no correction of typos, no reordering. They are the source, not our
reading of it, and the derived documents are only trustworthy if these are.

## What is not here

The verbatim recordings of the working sessions, and the client's field workbook.
Both stay in the private build repository — the recordings because they are candid,
the workbook because it carries live borrower data. Every ruling they produced is
written up in [`../10-decisions.md`](../10-decisions.md), each citing its session by
date.
